# Grafana dashboards

Drop JSON dashboard definitions here. Suggested dashboards (build in Phase 4):

- **Receptionist overview** — calls/min, answer rate, error rate, p95 latency
- **Cost** — daily spend by component (telephony, STT, TTS, LLM)
- **Calls** — call list table, transcripts, tool calls
- **Latency** — STT first token, LLM first token, TTS first byte, E2E
- **Knowledge gaps** — unanswered questions over time
